## A. 格式合规（vault 规范）

- [ ] frontmatter 12 个字段名与规范 §6 **逐字一致**：title / date / architect / year / location / type / status / rating / feature / cover / tags / aliases
- [ ] 无第 13 个结构化字段（面积/结构/业主等细项只在正文「基本信息」）
- [ ] `type` == 所在文件夹名 == `#architecture/type/` 主标签（受控长词）
- [ ] `status` == `待整理`（冲突未裁决时 == `待核查` 且文首有 warning callout）
- [ ] `rating` 留空
- [ ] `year` 来源未确认则留空；**无任何臆造数据**
- [ ] `feature` 有一句话亮点且有来源支撑
- [ ] 文件名 `{项目名}，{城市} - {建筑师}.md`（全角逗号），不含 `\ / : * ? " < > |`

- [ ] 标签：type 主标签 1 个必填；architect 1–3；feature 2–6（可复用词）；material 1–5（具体材料）
- [ ] 新标签已在 `00 - Meta/标签体系.md` 查重；查不到的 → 已列入回执「待登记标签」，未写入笔记
